## Requirements
Generate comprehensive tests that cover:

### For Python (pytest):
1. **Happy Path Tests**: Test successful execution with valid inputs
2. **Edge Cases**: Test boundary conditions, empty inputs, null values
3. **Error Cases**: Test invalid inputs, exceptions, validation errors
4. **Async Tests**: Use @pytest.mark.asyncio for async functions
5. **Fixtures**: Create fixtures for common test data
6. **Mocking**: Mock external dependencies (database, API calls)
7. **Assertions**: Use specific assertions (assert ==, assert in, pytest.raises)
8. **Type Checking**: Verify correct types are returned

### For TypeScript/React (Vitest):
1. **Rendering Tests**: Test component renders correctly
2. **User Interaction Tests**: Test button clicks, form inputs, events
3. **State Management Tests**: Test useState, useEffect hooks
4. **Props Tests**: Test different prop combinations
5. **Accessibility Tests**: Use accessible queries (getByRole, getByLabelText)
6. **Error States**: Test error handling and display
7. **Loading States**: Test loading indicators
8. **Mock Functions**: Use vi.fn() for callbacks
