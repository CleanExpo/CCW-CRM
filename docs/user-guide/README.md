## System Requirements

### End Users

- **Browser**: Chrome 90+, Firefox 88+, Safari 14+, or Edge 90+
- **Internet**: 10 Mbps minimum (broadband recommended)
- **Screen Resolution**: 1366x768 minimum (1920x1080 recommended)
- **JavaScript**: Must be enabled

### Administrators

- **All end-user requirements** plus:
- **Command Line Access**: For advanced configuration
- **Database Access**: For maintenance tasks
- **SSH Access**: For server management

### Developers

- **All end-user requirements** plus:
- **API Client**: Postman, Insomnia, or similar
- **Programming Knowledge**: JavaScript/TypeScript or Python
- **JSON Understanding**: For API requests/responses
