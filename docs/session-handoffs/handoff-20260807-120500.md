Three files (`docs/claude-memory-system.md`, `docs/features/AUTH_OAUTH_DEPLOYMENT.md`,
`docs/features/AUTH_OAUTH_REQUIREMENTS.md`) were stored as CRLF blobs while `.gitattributes`

merge — `checkout` and `stash` could not clear it, because the stored blob was the problem.

`main` had already committed the LF versions in #273, so those were taken, as a separate commit
`b91b172a`. It is line-endings only: `git diff --cached --ignore-cr-at-eol` over the change was
empty before committing. It is called out here because a 567-line diff in a docs-only branch looks
alarming and deserves an explanation rather than a discovery.
