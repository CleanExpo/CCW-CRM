## Usage Notes

- Run at 1792x1024 (16:9) or 1024x1024 (1:1) resolution
- Generate 4 variants per prompt and select best
- Add to CCW asset library with prompt metadata for reproducibility
- For A/B testing: vary time of day, technician demographics, product placement
- Use Imagen 4 Fast for social media drafts, Imagen 4 for final assets
