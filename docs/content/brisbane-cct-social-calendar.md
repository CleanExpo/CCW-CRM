**Copy**:
IICRC CCT preview: Stain chemistry

Not all stains are the same and treating them the same way leads to callbacks.

The CCT covers:

- Oxidisable stains (coffee, tea, red wine)
- Protein stains (blood, food, pet)
- Tannin stains
- Oil-based stains
- And the ones that combine all of the above

Knowing the stain type before you spray is the difference between a clean result and a permanent set.
