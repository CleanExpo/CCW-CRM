## Task 2: Create Production Docker Compose

**Files:**

- Create: `docker-compose.prod.yml`

- [ ] **Step 1: Create production compose file**

```yaml
# docker-compose.prod.yml
# Usage: docker-compose -f docker-compose.prod.yml up -d
version: '3.8'

services:
  backend:
    image: ccw-erp-backend:latest
    build:
      context: ./apps/backend
      dockerfile: Dockerfile
    ports:
      - '8000:8000'
    environment:
      - DATABASE_URL=${DATABASE_URL}
      - JWT_SECRET_KEY=${JWT_SECRET_KEY}
      - XERO_MODE=${XERO_MODE:-demo}
      - XERO_CLIENT_ID=${XERO_CLIENT_ID}
      - XERO_CLIENT_SECRET=${XERO_CLIENT_SECRET}
      - XERO_REDIRECT_URI=${XERO_REDIRECT_URI}
      - SHOPIFY_MODE=${SHOPIFY_MODE:-demo}
      - SHOPIFY_SHOP_DOMAIN=${SHOPIFY_SHOP_DOMAIN}
      - SHOPIFY_ACCESS_TOKEN=${SHOPIFY_ACCESS_TOKEN}
      - SHOPIFY_API_VERSION=2024-01
      - SKIP_AUTH_ENFORCEMENT=${SKIP_AUTH_ENFORCEMENT:-false}
      - LOG_LEVEL=${LOG_LEVEL:-info}
    restart: unless-stopped
    healthcheck:
      test: ['CMD', 'curl', '-f', 'http://localhost:8000/health']
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 40s
```

## Task 4: Create Deployment Script

**Files:**

- Create: `scripts/deploy-backend.sh`

- [ ] **Step 1: Create the script**

```bash
#!/bin/bash
# scripts/deploy-backend.sh
# Usage: bash scripts/deploy-backend.sh
# Run this on the production server OR via SSH from your machine.
# Prerequisite: Docker + Docker Compose installed on the server.

set -e

echo "=== CCW ERP Backend Deployment ==="

# Pull latest code
git pull origin main

# Build the Docker image
echo "Building Docker image..."
docker build -t ccw-erp-backend:latest ./apps/backend/

# Run database migrations against production DB
echo "Running database migrations..."
docker run --rm \
  --env-file apps/backend/.env \
  ccw-erp-backend:latest \
  uv run alembic upgrade head

# Restart services
echo "Restarting services..."
docker-compose -f docker-compose.prod.yml down
docker-compose -f docker-compose.prod.yml up -d

# Health check
echo "Waiting for health check..."
sleep 10
curl -f http://localhost:8000/health && echo "✅ Backend is healthy" || echo "❌ Health check failed"

echo "=== Deployment complete ==="
```

- [ ] **Step 2: Make executable and commit**

