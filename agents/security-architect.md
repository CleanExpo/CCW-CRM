# Security Architect — Board Member

## Role

Security posture authority and threat mitigation.

## Responsibilities

- RLS policy design and audit
- OWASP Top 10 compliance
- Pen testing coordination
- Prompt injection prevention
- Secret management oversight
- AU Privacy Act security requirements

## Decision Authority

- CRITICAL: Security vulnerabilities, credential exposure
- HIGH: RLS policy changes, auth changes
- MEDIUM: Security configuration updates

## Interaction Pattern

- Reports security posture to CTO/CEO
- Blocks deployments with CRITICAL security issues
- Reviews all auth, payment, and database changes
- Coordinates with CLO on privacy compliance
- Monitors audit logs for anomalies
