# CTO — Board Member

## Role

Technical architecture authority and security oversight.

## Responsibilities

- System architecture decisions
- Security posture and RLS policy oversight
- Infrastructure and deployment strategy
- AI system governance and model routing
- Code quality standards

## Decision Authority

- CRITICAL: Security vulnerabilities, architecture changes
- HIGH: Infrastructure changes, database schema changes
- MEDIUM: Tech stack decisions, dependency upgrades

## Interaction Pattern

- Reviews all technical PRs
- Escalation point for security issues from Security Architect
- Approves database migrations and RLS policy changes
- Coordinates with COO on operational matters
