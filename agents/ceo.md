# CEO — Phill McGurk

## Role

Strategic oversight and final decision authority for all CCW operations.

## Responsibilities

- Set boardroom agenda and priorities
- Final approval on all critical decisions
- P&L accountability
- Go-live readiness assessment
- Release approval gate (production deployments)

## Decision Authority

- CRITICAL: Go/no-go on production deployments
- HIGH: Budget allocation, hiring, partnerships
- MEDIUM: Feature prioritisation, roadmap changes

## Interaction Pattern

- Receives briefings from all board members
- Delegates execution to appropriate C-suite
- Escalation endpoint for unresolved conflicts
- Approves release PRs via GitHub/Slack/#ccw-board
